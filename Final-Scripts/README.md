# Final Scripts

Each `dayN_final.R` is the complete, runnable version of that day's **Part 2 -- Guided coding** walkthrough from the matching workbook in `Materials/Day N/`, including its optional-demonstration code block. Run a day's script top to bottom to reproduce everything shown live during that session.

These differ from the other two script folders:

- `Starter-Scripts/` -- participant-facing exercises with `TODO` markers (Part 3 practice and the baseline task).
- `Solution-Scripts/` -- facilitator-reviewed answer keys for those same exercises.
- `Final-Scripts/` (this folder) -- the guided-coding demonstration code itself.

Day 7's script is a plain-R reference for the code chunks only; the real Day 7 deliverable is the rendered Quarto report (`Quarto-Template/capstone-report.qmd`, with a facilitator-reviewed example in `Solution-Scripts/day7_capstone_report_solution.qmd`).
